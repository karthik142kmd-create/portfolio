# Personal Portfolio 💻

A simple **static personal portfolio website** built to showcase my skills, projects, and learning journey as a B.Tech student.

## 🌐 Live Demo

[View Portfolio](https://sampleportfolio100.netlify.app/)

## 📌 About

This portfolio was created using basic frontend technologies to practice building and deploying a real-world website.

It contains information about my:

* Skills
* Projects
* Education
* Interests
* Problem-solving journey

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Git
* GitHub

## ✨ Features

* Clean and simple user interface
* Responsive layout
* Project showcase
* Skills section
* Personal information section
* Static website deployment

## 🚀 Deployment

The portfolio is deployed using **Netlify**.

The project helped me understand the basic workflow of:

**Development → Git → GitHub → Deployment → Live Website**
